# Kasir Laravel

Aplikasi kasir berbasis web yang dibangun menggunakan Laravel untuk membantu pengelolaan produk, kategori, transaksi penjualan, stok, dan laporan penjualan.

Project ini dibuat sebagai project portfolio untuk menunjukkan kemampuan dalam membangun dan melakukan maintenance aplikasi web menggunakan Laravel.

---

## ✨ Features

### Authentication

- Login
- Logout
- User authentication
- Role-based access control

### Dashboard

- Ringkasan penjualan hari ini
- Total transaksi
- Total produk terjual
- Produk dengan stok menipis
- Produk terlaris
- Grafik penjualan 7 hari terakhir

### Product Management

- Menampilkan daftar produk
- Search produk
- Pagination
- Tambah produk
- Edit produk
- Hapus produk
- Detail produk
- Pengelolaan stok
- Relasi produk dengan kategori

### Category Management

- Menampilkan kategori
- Tambah kategori
- Edit kategori
- Hapus kategori
- Relasi kategori dengan produk

### Transaction / POS

- Membuat transaksi penjualan
- Memilih produk
- Search produk
- Mengatur jumlah produk
- Perhitungan subtotal otomatis
- Perhitungan total transaksi
- Input pembayaran
- Perhitungan kembalian
- Validasi stok
- Pengurangan stok otomatis
- Nomor invoice otomatis
- Detail transaksi
- Cetak struk

### Sales Report

- Filter laporan berdasarkan periode
- Total penjualan
- Total transaksi
- Total produk terjual
- Daftar transaksi berdasarkan periode
- Export laporan ke CSV
